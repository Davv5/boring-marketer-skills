# Post-purchase Format

Read during sequence planning when the subscriber has purchased. Build 4–6 emails that onboard, help the customer reach a first win, reduce avoidable refunds, and introduce a relevant next offer after value is delivered.

## Email purposes and file names

1. `01-welcome-aboard.md` — welcome the customer and explain access and support.
2. `02-quick-start.md` — give the shortest useful path to getting started.
3. `03-first-win.md` — help them achieve and recognize an early result.
4. `04-advanced-tip.md` — deepen useful product adoption.
5. `05-community.md` — invite participation when a real community exists.
6. `06-upsell.md` — connect demonstrated value to an appropriate next offer.

Use only relevant emails within the selected length; confirm product access, support, community, and offer facts rather than inventing them. Select send days and times through `references/send-timing.md` using the audience and actual onboarding needs.

Completion: every planned email has a supported purpose, send timing, and CTA, and the first-win path precedes the upsell.
