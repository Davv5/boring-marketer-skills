# Changes from the original v2.0

Rewritten against Matt Pocock's `/writing-for-agents`. Decisions and reasons: [`docs/rewrite-decisions.md`](docs/rewrite-decisions.md) and [`docs/adr/`](docs/adr/).

- **Markdown output** ([ADR 0002](docs/adr/0002-markdown-output-format.md)). The box-drawing output system is gone. Every skill answers in the four sections (Header, Content, Files Saved, What's Next) with ✓ ✗ ★ → symbols. `_system/output-format.md` shrank from 927 lines to the contract; skill-specific layouts moved into their skills.
- **Shared `_system` files are the single source** ([ADR 0003](docs/adr/0003-system-files-single-source.md)). `brand-memory.md` is organised by branch (Read, Write, Feedback, then Campaigns, Stack and tools, Data-quality label). Skills no longer restate it: each keeps its Reads, Writes, a load step and a feedback step pointing at it. Feedback uses one prompt everywhere. Freshness and volume rules apply on every run, direct or dispatched. New shared files: `ai-tells.md` (`/direct-response-copy`, `/seo-content`) and `content-brief.md` (`/keyword-research` writes it, `/seo-content` reads it).
- **The central per-skill context lists are deleted** ([ADR 0004](docs/adr/0004-per-skill-reads-replace-context-matrix.md)): the matrix at the bottom of `/start-here` and the per-skill table in `brand-memory.md`. Each skill's Reads list, with depth, is the only source; `/start-here` dispatches by pointer plus session-only facts.
- **Skills are short entry files with disclosed detail.** Every SKILL.md is under 500 lines and holds Reads, Writes, steps and completion criteria. Modes (`modes/`), Formats and large detail (`references/`) load only at the step that needs them: `/brand-voice` Extract, Build and Scrape; `/lead-magnet` Ideate and Build; `/seo-content` Refresh; `/content-atomizer` Calendar and one file per platform; `/direct-response-copy` Testing; `/newsletter` one file per Format; `/email-sequences` one file per sequence type; `/start-here` first run, returning run, routing, workflows, dispatch, campaigns and stack detection. Terms are fixed in [`GLOSSARY.md`](GLOSSARY.md).
- **`/creative` lineup updated** from the researched lineup ([`docs/research/replicate-models-2026-10.md`](docs/research/replicate-models-2026-10.md)). `creative/references/MODEL_REGISTRY.md` is the only home for model slugs and prices (role, slug, reason, verified-on date); the modes name roles. Payload bodies no longer carry a `model` field. Hero comparison runs only on request, with estimated cost first. The broken `modes/product-photos.md` and `product-videos.md` pointers are fixed. Without a Replicate token `/creative` writes prompts (a Fallback).
- **Schemas trimmed and wired.** `ad-matrix` and `campaign-brief` schemas are deleted: campaign briefs are markdown defined in `brand-memory.md` §Campaigns, and the optional ad matrix lives in `/positioning-angles` as markdown. `voice-profile`, `keyword-plan`, `content-brief` and `email-sequence-summary` remain, each tied to the skill that writes it (JSON block in a `<details>` section under the markdown).
- **Lint and health check.** `_system/scripts/lint-skills.sh` checks that every pointer resolves, every mode and reference file is pointed to, frontmatter has a name and description, and no box-drawing characters appear; it warns over 500 lines. `doctor.sh` runs it for the whole pack. The scripts derive skill and file lists from the folders, and `e2e-fresh-install.sh` and `package.sh` bugs that failed on the original are fixed. The review standard is [`docs/agents/standards.md`](docs/agents/standards.md).
- **Docs.** `ARCHITECTURE.md` is design reasoning pointing at the ADRs and skills, without line or check counts. `The Vibe Marketing Playbook.md` moved to `docs/playbook.md` and is linked from the README as background reading.

Earlier edits kept: descriptions are short; `/start-here` is user-invoked (`disable-model-invocation: true`) and the other 10 skills stay model-invoked; dead references to `/audience-research`, `/competitive-intel`, `/paid-ads`, `/landing-page` and `/cro` are removed (`audience.md` and `competitors.md` are still read; write them by hand); `_system` paths resolve from each skill's folder (`../_system/…`).
