# Vibe Marketing Skills

A pack of marketing skills that share one brand memory and hand work to each other. This glossary fixes the words the skills use for how a run behaves.

## Runs

**Mode**:
The kind of work a single run of one skill does, such as `/brand-voice` Extract, `/creative` Product Photo, `/seo-content` Refresh, `/lead-magnet` Build, or `/content-atomizer` Calendar. Each mode can have its own disclosed file.
_Avoid_: using "mode" for first-run vs. returning, or for data quality

**First run**:
A run where the skill's owned brand file does not exist yet, so it builds from scratch.
_Avoid_: Creation Mode, Build Mode (when it means this)

**Returning run**:
A run where the skill's owned brand file already exists, so it offers a targeted update.
_Avoid_: Returning Mode, Update Mode, Iteration

**Fallback**:
What a skill does when a tool or key it uses is missing, such as `/creative` writing prompts when there is no Replicate token. Not a Mode.
_Avoid_: Prompt-Only Mode

**Format**:
A choice of output shape inside one Mode, each with its own disclosed file, such as a `/newsletter` deep-dive or curated-links edition.
_Avoid_: type, template (when it means this)

**Data-quality label**:
The tag on research output saying whether it came from live web search (LIVE) or the model's own knowledge (ESTIMATED).
_Avoid_: Research Mode
