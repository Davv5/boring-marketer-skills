# Each skill's Reads list replaces the Context Matrix

Upstream kept a Context Matrix of which brand files each skill receives in `/start-here`, partly repeated in `brand-memory.md` and in each skill, and the three copies contradicted each other (e.g. whether `/direct-response-copy` gets the creative kit). Each skill's own Reads list, stated positively with depth (e.g. "positioning.md: chosen angle only"), is now the only source; `/start-here` dispatches by pointer and the skill loads its own reads. Do not restore a central matrix: it becomes a stale copy of the skills.
