# Testing Mode

Read this file only when the user requests variants, scoring, or A/B testing.

## Variants

- Headlines: provide at least five meaningfully different options; put the recommended option first and mark it ★.
- Long-form landing or sales pages: provide control and one distinct alternative angle. Add a proof-led variant when strong evidence exists.
- Email: provide five subject-line options, with ★ on the recommendation.
- State the audience or condition each option suits; keep the underlying offer and facts consistent.

## Scoring

When asked to evaluate existing or generated copy, score clarity, specificity, voice, desire, proof, urgency, and flow from 1–10. Give a concise reason per dimension, total out of 70, an evidence-based verdict, and prioritized fixes. Treat urgency as authentic only when the brief supports it.

## A/B tests

Suggest tests only when requested. For each, state the element and alternatives, hypothesis, target metric, expected direction, and priority. Prioritize headline, opening, and CTA before secondary refinements. Describe impact as a hypothesis, not a forecast or guarantee.

**Done when** requested testing material is delivered in the Content section with recommendations and rationale, without inventing evidence or expected lift.
