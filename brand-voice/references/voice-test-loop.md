# Voice Test Loop

Run this validation after generating a profile from any Mode and before saving.

## Generate three samples

Write:
1. **Email opening:** 3–4 sentences that feel like a real send and demonstrate greeting style, sentence rhythm, vocabulary, and personality.
2. **Social post:** LinkedIn or Twitter/X, matching the brand's most active platform and its profile adaptation.
3. **Landing-page hero:** Headline, subheadline, and 1–2 supporting sentences; use benefit-focused direct-response voice without generic copy.

Ask: “Does this sound like you?” Offer:
- Yes, that nails it — save and finish.
- Close but needs adjustment — say what feels off (tone, vocabulary, rhythm, or another dimension); adjust relevant profile sections, regenerate all three samples, and repeat.
- Not quite right — ask for a right-sounding example or specifics (too formal, casual, safe, aggressive, etc.). Analyze provided examples with Extract Mode, rebuild the sections that missed, regenerate all samples, and repeat.

## Three-round checkpoint

After three rounds without confirmation, offer to save the current version for later refinement, take one more round if the likely fix is clear, or restart in Build Mode with its 15 questions. A provisional save requires the user's choice.

**Done:** The user confirms the samples or explicitly chooses a provisional save after considering the available next steps.
