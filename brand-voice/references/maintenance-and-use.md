# Using and revisiting the profile

## Downstream use

The profile is an input to the other skills. Use the platform-specific guidance relevant to the requested deliverable:

- **direct-response-copy:** match tone, vocabulary, and style; landing-page adaptation for copy.
- **lead-magnet:** align the hook and framing with the profile.
- **email-sequences:** use email adaptations.
- **seo-content:** use blog/SEO adaptations to maintain voice at length.
- **content-atomizer:** use the adaptation for each channel when repurposing content.
- **newsletter:** use email adaptations, with the newsletter's own personality where appropriate.
- **creative:** match the headline to landing-page adaptations while keeping it on-brand.

Run `/brand-voice` before content work when no usable profile exists. Confirm the voice with the test loop; save it to `./brand/voice-profile.md`. Other content skills read this file through their brand-memory Reads lists.

## Revisit signals

Revisit the profile when the brand evolves or pivots, the audience changes significantly, current voice is not converting, new team members need onboarding, content becomes inconsistent, the brand moves to a new platform, A/B tests reveal tone preferences, or feedback from `/email-sequences` or `/direct-response-copy` suggests the profile is off. On a returning run, begin from the existing profile and ask which part needs attention.

## Quality test

A useful voice profile is:
1. **Recognizable:** content could be identified as theirs without a byline.
2. **Actionable:** a writer could produce on-brand content using the profile.
3. **Differentiated:** it sounds distinct from competitors.
4. **Authentic:** it reflects who they are or want to be.
5. **Consistent:** it applies across social, email, and long-form formats.
6. **Adaptive:** platform guidance shifts voice without losing identity.

When a criterion is not met, strengthen the relevant profile evidence or ask the user to resolve the gap.
