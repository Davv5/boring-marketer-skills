# Mode fallbacks

Read when a Mode lacks its required input or evidence.

## Extract has no content

Explain that Extract needs existing material to identify voice patterns. Ask for 3–5 pieces the user is proud of (website copy, emails, or posts), or offer Build's strategic questions or Scrape from a URL if search is available.

## Scrape finds insufficient content

Treat a corpus below roughly 500 words as insufficient for reliable voice extraction. Report what was found—for example, homepage word count, whether About/blog/social sources were found—and explain the limitation. Offer pasted content for Extract or the 15 Build questions. Do not infer a profile from sparse content.

## Web search is unavailable

Say that web search is unavailable and Scrape cannot run in this environment. Offer pasted website copy for Extract or strategic questions for Build, and proceed only after the user chooses.
