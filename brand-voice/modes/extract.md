# Extract Mode

Use for a first run or returning run with representative existing content.

1. Ask for 3–5 pieces the user considers representative: website copy, emails, social posts, newsletters, or transcripts. Use available supplied content directly; prioritize varied contexts and authentic samples.
   **Done:** You have enough source material to compare repeated patterns, or the user chooses another Mode.
2. Analyze tone, vocabulary, rhythm, structure, personality, and point of view. Separate observed patterns from interpretation, and note contradictions or thin evidence.
   **Done:** Each dimension has grounded observations or an explicit evidence gap ready for the profile.
3. Draft from those observations, retaining distinctive details and useful examples. The main skill runs the profile test and save steps.
   **Done:** The draft's claims trace to source material or are marked as user-confirmed interpretation.
