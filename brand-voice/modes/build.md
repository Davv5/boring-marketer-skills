# Build Mode

Use when the user is starting fresh, has generic existing material, or wants an intentional evolution. Treat answers as the intended voice, not evidence of current practice.

1. Ask about identity and beliefs, background and difference, audience and trust, positioning, admired voices and anti-models, signature and avoided language, and comfort with humor or profanity. Ask follow-ups where answers conflict.
   **Done:** The user has supplied usable answers across identity, audience, positioning, aspiration, and practical constraints, or gaps are explicitly identified.
2. Synthesize the answers into personality traits, tone positions, vocabulary, rhythm, examples, boundaries, and platform adaptations. Consult the platform guide named in the main skill.
   **Done:** Every profile requirement is supported by user input or clearly marked as a proposed choice for confirmation.
